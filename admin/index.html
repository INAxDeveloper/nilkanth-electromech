How Auto-Publish Works

When you make edits to products, services, or contact details and click "Save & Publish":

  1. Your changes are instantly packaged into data/site-data.json.
  2. Saved directly to your GitHub repository (INAxDeveloper/nilkanth-electromech) via GitHub API.
  3. GitHub Pages automatically deploys the update in 30–60 seconds.
  4. Zero server cost — completely free forever!
